# 2026-09-24

## 沙龙报名页面 H5

**交付**:`salon-signup.html`(单文件 H5,移动端优先,扫码进入)

**核心实现**:
- 4 个必填字段:姓名 / 手机号 / 公司 / 职务
- 手机号正则 `/^1[3-9]\d{9}$/`;失焦即校验,错误时红字 + 边框变红 + 浅红底
- 输入时自动清除错误态,不持续打扰
- 提交时全量校验,未过则聚焦首个问题字段
- 按钮文案「锁 定 席 位」,下方红点 +「仅剩 7 个席位」制造稀缺感
- 提交成功后切换到极简对勾页 +「我们会在 1 个工作日内短信通知您席位。」

**设计要点**(30-50 岁企业管理者 / 商务克制):
- 主色深藏蓝 `#0a2540`(Stripe 蓝);统一圆角 8px;纯白底
- 输入框 50px / 按钮 54px 高,字号 16px 防 iOS 缩放,`inputmode="numeric"` 弹数字键盘
- 仅保留输入框边框过渡(0.2s UX 反馈),按钮按下无 transform / 无淡入淡出
- 元信息用细线分隔,字母大写 + 字距做英文小标识(SUMMIT / 2026 · AUTUMN)
- 必填项用红色 `*` 标记,辅助色用红 `#c8102e`

**占位内容**(用户需自行替换):
- 沙龙主题、时间、地点、品牌名 SUMMIT、紧迫感数字 7、主办方声明
