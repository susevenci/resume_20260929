## 13. 验收用例

打开页面后建议按以下顺序跑一遍：

- [ ] 添加 3 条明日行程（含不同时间）
- [ ] 添加 5 条待办，勾选其中 2 条
- [ ] 添加 3 张便签，每张写不同内容
- [ ] 添加 2 个问题
- [ ] 在日记区写 100 字以上
- [ ] 添加 2 个学习项，分别设 30% / 80%
- [ ] 在感悟区写内容
- [ ] 关闭浏览器，重新打开 → 数据仍在
- [ ] 点击「导出 JSON」→ 得到文件
- [ ] 点击「导出 Markdown」→ 得到可读 md 文件
