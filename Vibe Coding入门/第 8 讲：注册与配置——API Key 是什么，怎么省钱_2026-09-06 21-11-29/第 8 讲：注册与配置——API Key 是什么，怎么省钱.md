## 一、开篇：两种烧钱的方式

先给你看两份真实的"新手账单"。

**账单 A：** 小赵入门第一天，听说某个顶级模型最牛，直接订阅了它的高级会员（约 150 元/月）。接下来的两周，她用它聊天、问问题、写周报、偶尔做个页面——和她用免费工具干的事一模一样。月底她根本想不起来这笔订阅费花出了什么价值。

**账单 B：** 小钱听说"按量付费很便宜"，申请了一个平台的 API，绑上工具就开用。但她不知道的是，她选的那个模型是平台里最贵的档位，而且她有个习惯：一个问题和 AI 聊上七八十轮，每轮 AI 都要把前面的聊天记录重新读一遍。三天后，账户里的 50 元见底，她都不知道钱是怎么没的。

这两种烧钱方式，一个叫\*\*"为用不上的能力买单"**，一个叫**"为不理解的习惯交税"\*\*。

这一讲的目标：让你既不成为小赵，也不成为小钱。入门阶段，你的合理成本是——\*\*0 到 30 元每月，正常消耗不超过一杯奶茶钱。\*\*而且我要给你的不只是省钱技巧，是一套判断"什么时候该花钱、花在哪儿"的方法论。这套方法论，你将来做任何 AI 相关的决策都用得上。

## 二、API Key 到底是什么（三分钟讲透）

### 2.1 用视频会员类比

你家里有三台设备：电视、平板、手机。你在视频网站上买了会员，怎么让三台设备都能看？——登录同一个账号。

现在换一个场景：AI 公司（比如 DeepSeek、智谱、月之暗面）就像一个"智能视频网站"，它们的"会员"就是**按使用量计费的服务**。你的各种工具（对话窗口、工作台软件）就像那三台设备。怎么让工具能使用 AI 公司的服务？

答案就是 API Key：**一串几十位的字母数字密码，相当于你的"计费账号登录凭证"。**

流程是这样的：

1.  你去 AI 公司的"开放平台"（网站后台）注册账号；

1.  在后台找到"API Key"页面，点"创建"，得到一串密码（形如 `sk-xxxxxxxxxxxxxxxx`）；

1.  把这串密码填进你的工具（工作台型软件的设置页里通常有专门一栏）；

1.  此后这个工具每次调用 AI，都会带着这串密码——AI 公司就知道："哦，这是你的用量，记你账上。"
    

### 2.2 三个关键认知

**认知一：API Key 是"后付费"，不是充值卡。**

大多数平台是先给一点免费额度（几块钱到十几块钱不等），用完后按量扣费（你充多少用多少）。它不像视频网站包月，更像手机话费：用多少算多少。

**认知二：新手期你可能根本不需要它。**

注意一个容易混淆的点：**"AI 工具的网页/App 版"和"API"是两条独立的路。**

-   你用 Kimi 网页版、豆包 App、DeepSeek 网页版聊天——走账号体系，免费或会员制，**不需要 API Key**；

-   你让工作台型软件（如 Cursor/Trae 的某些配置）调用模型——走 API 体系，**这时候才需要 Key**。
    

所以结论很清晰：\*\*前 2-3 周的对话型学习阶段，一分钱不用花在 Key 上。\*\*等到第 3 周搬进工作台型工具，再申请不迟。

**认知三：Key 泄露 = 钱包敞口。**

API Key 绑着你的账户余额。它泄露了（比如截图发到群里、贴到公开论坛），别人就能拿它疯狂调用，烧你的钱。所以两条纪律：① Key 只存在自己的备忘录/密码管理器里；② 怀疑泄露，立刻去平台后台点"重置"（旧 Key 作废，生成新的）。

## 三、计费的基本逻辑：钱是按"字"算的

要省钱，先得知道钱花在哪儿。AI 计费的核心单位叫 **Token**，你可以粗暴地理解为"字数"——大约 1 个汉字 ≈ 1-2 个 Token，1 个英文单词 ≈ 1 个 Token。

**关键公式：**

```Plain
一次对话的费用 =（你发过去的字数 + AI 回复的字数）× 该模型的单价
```

这个公式里藏着两个烧钱的秘密，小钱踩的坑就在这里：

**秘密一：AI 每轮都要"重读"聊天记录。**

你跟 AI 聊到第 50 轮时，它处理你第 50 句话的方式，是把前面 49 轮全部内容重新读一遍再回答。也就是说，**对话越长，每一轮的成本越高**——同一个模型，第 2 轮可能花 0.001 元，第 50 轮可能要花 0.05 元。

**推论：新任务开新对话。** 一个话题做完就开新窗口，别在一个对话里聊到天荒地老。这个习惯能省 50% 以上的费用。

**秘密二：不同模型单价能差 10-50 倍。**

同样是写代码，顶级模型（如 Claude 顶级版）和便宜模型（如 DeepSeek、GLM 系列）的单价能差出一个数量级。而很多活，便宜模型干得一样好。

**推论：分工，而不是全程顶配。** 这就是下面要讲的省钱核心。

## 四、省钱核心心法：两个模型分工

这是本资料包最值钱的技巧，没有之一。请你把它当成口诀背下来：

> **便宜模型磨功能，贵模型做设计。**

### 4.1 为什么这样分工

把一个作品的诞生过程拆成两类活：

**第一类：逻辑活。** 搭功能、写结构、修 bug。这类活的特点是**对错分明**——按钮点了有没有反应、数据存没存上，有客观标准。便宜模型在这类活上的表现，和顶级模型的差距很小（都能做对），但价格差 10 倍。

**第二类：审美活。** 配色、排版、间距、动效、文案的语气。这类活的特点是**高下微妙**——"能用"和"高级"之间隔着一层感觉。这层感觉，顶级模型确实明显更好。这类活值得花钱。

\*\*策略：整个作品 80% 的对话用便宜模型完成（功能全部做对），只在最后一步切到贵模型做一次"整体设计优化"。\*\*贵模型只出场一次，几块钱；如果全程用它，同样的作品要花几十块。

### 4.2 成本对照表（一个中等复杂度作品）

|     |     |     |     |
| --- | --- | --- | --- |
| 方案  | 功能开发 | 设计打磨 | 总成本 |
| 全程顶级模型 | 约 15-30 元 | 约 5 元 | **20-35 元** |
| 分工方案 | 约 1-3 元（便宜模型） | 约 5 元（贵模型一次） | **6-8 元** |
| 极致省钱方案 | 免费额度（DeepSeek 网页版） | 免费额度试用 | **0 元** |

一个作品省 20 元，你做 10 个作品就是 200 元——这就是"一杯奶茶钱/月"的实现路径。

### 4.3 具体操作：什么时候切换

```Plain
第 1-4 步（毛坯版、能用版）→ 便宜模型
        ↓ 功能全部验收通过
第 5 步（好看版）→ 切换贵模型，发"设计优化"指令
        ↓ 视觉定稿
第 6 步（又出 bug/加新功能）→ 切回便宜模型
```

切换时的标准话术（好看版启动指令，可收藏）：

> 这个页面的功能已经全部实现并验证通过。现在请你**只做视觉和交互优化，绝对不要改动任何功能逻辑**：
> 
> 1.  整体风格：【描述你要的感觉，如"简约高级、白底、藏蓝点缀"】；
> 
> 1.  优化排版：间距、字号层级、对齐；
> 
> 1.  优化细节：圆角、阴影、按钮的悬停效果；
> 
> 1.  保持响应式，手机上也要好看。
> 
> 1.  请直接输出完整的新代码。

## 五、另外三个省钱习惯（顺手就能养成）

**习惯一：大段资料让 AI 存成文件，别反复粘贴。**

你的简历原文、产品需求文档，每次对话都全文粘贴，每次都是几百上千 Token。让 AI 帮你存成 `素材/需求.md`，以后说一句"读取素材文件夹里的需求文档"即可。省 Token，也省你复制粘贴的时间。

**习惯二：简单问题不问贵模型。**

"这个报错什么意思""这个单词怎么翻译"——这种活免费工具随便答。把贵模型的每一次调用都留给"值得"的场合。

**习惯三：定期看用量页。**

每个平台后台都有"用量统计"。每周花 1 分钟看一眼：钱主要花在哪个模型、哪类对话上。看两周，你对自己钱花在哪就有了直觉——这种直觉本身就是最好的省钱武器。

## 七、常见坑（FAQ）

**Q1："免费额度用完了会怎样？"**

分平台：有的直接停用提示充值，有的降速。不会偷偷扣钱——所有平台都是"先充值后使用"或"明确订阅"，不存在"用超了自动扣信用卡"的情况（除非你主动绑了自动续费，绑之前看清楚）。

**Q2："平台送的额度会过期吗？"**

部分会（常见 30-90 天有效期）。所以别囤着不用——入门期就是烧免费额度的最佳时机。

**Q3："为什么我申请的 Key 填进工具后没反应？"**

三个高频原因：① 复制时带了空格或少复制了几位（重新完整复制）；② 填错了设置项（确认填的是对应平台的 Key，别把 DeepSeek 的 Key 填到 Kimi 的栏里）；③ 账户没余额了。还不行，把设置页面截图发给 AI 问。

**Q4："听说有人用'拼车'（共享账号），便宜很多，靠谱吗？"**

不推荐。共享账号意味着你的对话内容对别人可见（隐私风险），且随时可能被封。省的是小钱，赌的是你的数据和稳定。

**Q5："将来做大了，怎么控制成本？"**

到时候你会自然学到：缓存、批量处理、选择更便宜的模型档位。那是进阶话题。现在只需记住——**成本意识比成本技巧重要**，你已经在第一梯队了。
