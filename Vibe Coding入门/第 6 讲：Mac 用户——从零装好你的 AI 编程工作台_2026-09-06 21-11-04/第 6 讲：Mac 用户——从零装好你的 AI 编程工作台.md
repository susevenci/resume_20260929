## 一、开篇：比装手机 App 难不了多少

很多人一听"配置开发环境"就头皮发麻，脑海里浮现出黑窗口、英文命令、进度条卡死的画面。

请放心：**那是程序员的装机，不是你的。**

程序员装环境，是给电脑配一整套"能运行各种语言代码"的工厂设备；而你做 Vibe Coding，作品是 HTML 网页——它有个天大的优点：**不需要任何运行环境，双击就能在浏览器里打开。** 浏览器就是它的运行环境，而浏览器你早就有了。

所以你的装机清单只有三样东西，其中一样还已经装在你电脑里了。全程不需要打开终端、不需要输入任何命令、不需要管理员密码。比你装过的任何一个手机 App 复杂不了多少。

## 三、第一样：浏览器（已有，检查即可）

你的 Mac 自带 Safari，完全够用。如果你常用 Chrome，也没问题。

**唯一的建议：** 固定用其中一个来预览作品，养成习惯。因为不同浏览器偶尔有细微的显示差异，固定一个，排查问题时少一个变量。

**验证动作：** 打开浏览器，随便访问一个网站，正常显示 → 这件装备就到位了。

## 四、第二样：安装 VS Code（10 分钟）

### 4.1 它是什么，先破除恐惧

VS Code 的全名是"代码编辑器"，听起来很程序员。但对你来说，它就是一个**专门看文本文件的高级记事本**。你 90% 的时间里只会用到它四个功能：打开文件夹、新建文件、粘贴内容、保存。全部是按钮操作，没有一个命令。

为什么要用它而不用 Mac 自带的"文本编辑"？因为"文本编辑"有个坑：它默认把文件存成富文本格式（.rtf），会让你的网页打不开。VS Code 不会给你添这个乱。

### 4.2 下载与安装

1.  打开浏览器，访问 VS Code 官网：`code.visualstudio.com`；

1.  页面会自动识别你是 Mac，点大大的 **Download** 按钮；

1.  下载得到一个 `.zip` 文件，双击解压，得到 `Visual Studio Code.app`；

1.  把它拖进"应用程序"文件夹——和你装过的所有 Mac 软件一样。
    

### 4.3 第一次打开（两个常见拦路虎）

**拦路虎一："无法打开，因为它来自身份不明的开发者。"**

这是 Mac 对非 App Store 软件的标准提示，不是病毒警告。解法：打开"系统设置 → 隐私与安全性"，往下滚，会看到"已阻止使用 Visual Studio Code"，点旁边的\*\*"仍要打开"\*\*，输入密码确认。

**拦路虎二：满屏英文，慌。**

不用慌。给你一张"四个按钮"地图，其他全部忽略：

|     |     |
| --- | --- |
| 按钮位置 | 干什么用 |
| 左上角"文件 → 打开文件夹" | 把你的作品文件夹交给它 |
| 资源管理器里的"新建文件"图标 | 建新文件（如 index.html） |
| 中间的大空白区 | 粘贴 AI 给的代码 |
| 快捷键 Cmd + S | 保存（用它，养成肌肉记忆） |

### 4.4 装个中文包（可选，30 秒）

实在不习惯英文界面：点左边栏四个方块组成的"扩展"图标 → 搜索框输入 `Chinese` → 第一个"Chinese (Simplified)"→ 点 Install → 按提示重启。界面就变中文了。

## 六、点火测试：做出你的第一个页面（10 分钟）

三样装备齐了，现在完成一次完整的"点火"，验证整条流水线。

**第 1 步：建文件。**

打开 VS Code → 文件 → 打开文件夹 → 选择第 3 讲建的 `简历页作品/01-当前版`。在左侧文件列表右键 → 新建文件 → 输入名字 `hello.html`（注意带上 `.html`）→ 回车。

**第 2 步：要代码。**

切到浏览器，打开你的 AI 工具，发送这段话（一字不改）：

> 帮我写一个 HTML 文件。内容：一个庆祝页面，白色背景，页面正中央有两行字——第一行是大字"我的 Mac 工作台装好了"，第二行是灰色小字"点火测试成功"。要求：代码完整，我保存成 hello.html 后双击能直接打开。

**第 3 步：粘贴保存。**

AI 回复一大段代码。全部选中复制（从第一行到最后一行，别漏）→ 切回 VS Code → 点进 hello.html 的编辑区 → 粘贴 → **Cmd + S 保存**。

**第 4 步：见证。**

打开"访达"，找到 `简历页作品/01-当前版/hello.html` → **双击** → 浏览器打开，两行字端正地躺在页面中央。

**点火成功。** 你刚刚走通的这条流水线（说需求 → 复制 → 粘贴 → 保存 → 双击预览），就是你未来所有作品的生产线。区别只在以后需求更复杂、作品更漂亮，**流程一步都不会变。**

>     
> 
> 1.  要求：面向纯小白，不用任何术语；每步都说清"你会看到什么"。

### 武器 2：VS Code 私教（只教你用得上的 5%）

> 我是一个非技术背景的初学者，刚装了 VS Code，只用它来做一件事：管理 AI 帮我写的 HTML 文件。
> 
> 请只教我最必要的操作，教学要求：
> 
> 1.  只讲 5 个以内我必须会的功能（比如打开文件夹、新建文件、保存），每个功能一句话说清在哪、怎么点；

> 1.  明确告诉我哪些看起来很复杂的部分（侧边栏、终端、各种面板）可以完全忽略；

> 1.  给我 3 个最值得记住的快捷键（Mac 版）。

>

**为什么专业：** "只教我 X 个""告诉我哪些可以忽略""不要全面教程"——这三个约束是对抗 AI"知识倾倒欲"的关键。默认情况下它会给你一份百科全书，而你要的是一张便利贴。

## 八、常见坑（FAQ）

**Q1："M 系列芯片（M1/M2/M3/M4）的 Mac 要下特殊版本吗？"**

VS Code 官网下载的是通用版，自动适配，不用纠结。

**Q2："VS Code 免费吗？会不会用几天要收费？"**

完全免费，永久免费。它是微软出品的开源软件，放心用。

**Q3："我能不能直接用 Mac 自带的'文本编辑'代替 VS Code？"**

强烈不建议。它默认存富文本，会导致网页打不开。如果你一定要用：打开"文本编辑 → 设置"，把格式改成"纯文本"——但既然都要改设置，不如直接装 VS Code，一劳永逸。

**Q4："装完 VS Code，桌面多了一个叫 Visual Studio Code 的东西，能删吗？"**

那是解压出来的安装本体，已经拖进"应用程序"后，下载文件夹里的原文件可以删。"应用程序"里的别动。

**Q5："点火测试时双击 hello.html，跳出来的是 VS Code 而不是浏览器？"**

文件关联问题。右键 hello.html → 显示简介 → "打开方式"选你的浏览器 → 点"全部更改"。以后所有 .html 双击都默认浏览器打开。
