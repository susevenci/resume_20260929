## 一、开篇：Windows 装机，只有一个独家坑

先给你吃个定心丸：Windows 上配 Vibe Coding 环境，和 Mac 一样简单——浏览器你有了，VS Code 点几下就装好，AI 工具全是网页版。全程不碰命令行、不碰注册表。

但 Windows 有一个**独家坑**，90% 的 Windows 小白会在第一天就掉进去：**文件名后缀问题。** Windows 默认隐藏文件后缀名，你以为自己建的是 `index.html`，实际建出来的可能是 `index.html.txt`——然后双击打不开，你对着一个文本文件怀疑人生。

这一讲会把这个坑放在最显眼的位置，并且从根上给你解决掉。除此之外，一路坦途。

## 三、第 0 步（Windows 专属）：先解决后缀名问题

**这一步花 1 分钟，能避免你未来 80% 的"打不开"。**

1.  打开"文件资源管理器"（任务栏的文件夹图标）；

1.  点顶部的"查看"选项卡；

1.  找到并勾选\*\*"文件扩展名"\*\*（Windows 11：查看 → 显示 → 文件扩展名）。
    

勾完之后，你再看电脑里的文件，名字后面都多出了 `.docx`、`.jpg`、`.txt` 这样的尾巴。**从今天起保持这个显示，永远不要关。**

为什么重要：因为网页文件必须叫 `xxx.html`，后缀不对，浏览器不认。显示扩展名后，你一眼就能检查文件建对没有。

## 五、第二样：安装 VS Code（10 分钟）

### 5.1 它是什么

一个"专门看代码文件的高级记事本"。你只会用到它四个功能：打开文件夹、新建文件、粘贴内容、保存（Ctrl + S）。其他复杂界面全部可以无视。

### 5.2 下载与安装

1.  浏览器访问官网：`code.visualstudio.com`；

1.  点 Download for Windows，得到一个 `.exe` 安装包；

1.  双击运行，一路"下一步"。**安装选项页面建议全部勾选**（特别是"添加到右键菜单"——以后右键任何文件夹就能直接用 VS Code 打开，很方便）；

1.  完成，打开。
    

**唯一的忠告：只从官网下。** 搜索引擎结果页前几个"高速下载""安全下载"按钮，都是捆绑全家桶的下载器。认准官网域名。

### 5.3 装个中文包（可选，30 秒）

点左边栏"扩展"图标（四个方块）→ 搜索 `Chinese` → 安装第一个"Chinese (Simplified)"→ 重启 VS Code → 界面变中文。

## 七、点火测试：做出你的第一个页面（10 分钟）

**第 1 步：建文件。**

打开 VS Code → 文件 → 打开文件夹 → 选你的作品文件夹（如 `简历页作品/01-当前版`）→ 左侧右键 → 新建文件 → 输入 `hello.html` → 回车。

**建完立刻检查：** 文件名显示的是 `hello.html` 还是 `hello.html.txt`？如果多了 `.txt`，右键重命名，把 `.txt` 删掉。（这就是为什么第 0 步要先开扩展名显示。）

**第 2 步：要代码。**

切到浏览器，打开 AI 工具，发送：

> 帮我写一个 HTML 文件。内容：一个庆祝页面，白色背景，页面正中央有两行字——第一行是大字"我的 Windows 工作台装好了"，第二行是灰色小字"点火测试成功"。要求：代码完整，我保存成 hello.html 后双击能直接打开。

**第 3 步：粘贴保存。**

代码全部复制 → 切回 VS Code → 粘贴进 hello.html → **Ctrl + S 保存**。

**第 4 步：见证。**

打开文件资源管理器，找到 hello.html → **双击** → 浏览器打开，庆祝页面出现。

**如果双击后用记事本打开了：** 右键文件 → 打开方式 → 选择浏览器 → 勾选"始终使用此应用打开" → 确定。一次设置，永久生效。

**点火成功。** 这条流水线（说需求 → 复制 → 粘贴 → 保存 → 双击预览）就是你未来所有作品的生产线。

## 九、常见坑（FAQ）

**Q1："Windows 7/10/11 都能用吗？"**

Windows 10 和 11 完全没问题。Windows 7 太老了，新软件支持不好，建议升级系统。

**Q2："电脑是公司的，没有管理员权限，装不了软件怎么办？"**

三个对策：① VS Code 有免安装的便携版（ZIP 版，解压即用，不需要管理员权限）；② 对话型 AI 工具全是网页版，什么都不用装；③ 实在受限，前 10 讲的学习用"网页版 AI + 网页版编辑器"也能完成。

**Q3："杀毒软件/安全管家拦截 VS Code 正常吗？"**

偶有发生（误报）。从官网下载的 VS Code 是安全的，选择"允许"即可。如果连官网下载都拦，大概率是安全软件过度敏感。

**Q4："文件名到底是 hello.html 还是 hello.HTML？大小写有区别吗？"**

Windows 上不区分大小写，都能用。但养成全小写的习惯——因为将来部署到服务器上时，服务器是区分大小写的。

**Q5："C 盘快满了，VS Code 能装到 D 盘吗？"**

能。安装过程中有一步让你选安装位置，改到 D 盘即可。作品文件夹也建议建在 D 盘。
