# 周家弘 · 个人简历

一个纯静态的个人简历网页，无需构建、无依赖，直接打开即可浏览。

## 在线预览

开启 GitHub Pages 后可通过仓库地址访问；本地直接双击 `index.html` 或用任意静态服务器打开即可。

## 文件结构

```
11/
├── index.html   # 页面结构
├── resume.css   # 全部样式（含深色模式、A4 打印样式）
└── resume.js    # 全部交互
```

## 功能

- **名片式门面区**：姓名 + 一句话介绍，字号层级分明
- **个人优势**：三张并列卡片，移动端自动竖排
- **工作经历**：左侧竖线时间轴
- **顶部导航栏**：可跳转到 个人优势 / 工作经历 / 联系方式，右侧实时显示当前所在栏目
- **回到顶部按钮**：滚动一定距离后浮现
- **深色模式**：右上角开关切换浅色 / 深色，用 `localStorage` 记住上次选择，首次访问跟随系统偏好
- **打印简历**：一键调用浏览器打印，适配 A4 纸张排版
- **细节动效**：卡片悬停轻微浮起、页面滚动区块淡入（兼容 `prefers-reduced-motion`）

## 技术说明

- 样式通过 CSS 自定义属性（变量）统一管理配色，浅色 / 深色模式一键切换
- 交互使用原生 JavaScript，无第三方库
- 响应式布局，适配手机与桌面端
